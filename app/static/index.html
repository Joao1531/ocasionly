Usage

—

Fitting room (image-generating model)

Needs a model with image output. Google Gemini by default. According to its documentation, opencode's Gemini models only return text: to check with your account, point the URL to https://opencode.ai/zen/v1 and run the generation test (if the key is left empty, the opencode key is used). Generated images always have a plain, neutral background.

Edit garment

Import from folder

One subfolder per category (Tshirts, Shirts, Hoodie-Sweaters, Shorts, Trousers, Socks, Coats, Shoes, Accessories; Portuguese folder names work too). Each file name is read to fill in size, brand, model, colour, fit and material. You can correct everything afterwards by tapping the garment.
